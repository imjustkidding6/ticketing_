The platform has been updated. Here's what changed:

New features:
- Activity logs now capture all create, update, and delete actions across tickets, clients, and related records.
- Tickets can be permanently deleted by authorized users.
- New Spam folder: review and delete spam tickets. Spam is excluded from all ticket counts and reports.
- Admins can now broadcast system announcements to all users (like this one).
- New global settings panel available in the admin area.

Bug fixes:
- Fixed: changing a ticket status from On Hold to In Progress no longer throws an error.
- Improved: database errors now show a user-friendly page instead of a raw error screen.

No action is required. If anything looks off, please open a ticket.
